# Dashboard Screenshots

This directory contains screenshots of the Cloud Cost Analytics Dashboard.

## Screenshots to Capture

1. **Overview Tab** - Main dashboard with filters and price comparison chart
2. **Recommendations Tab** - Cost optimization recommendations and anomaly detection
3. **Pricing Models Tab** - On-Demand vs Reserved vs Spot comparison
4. **Instance Finder Tab** - Instance recommender based on workload requirements
5. **Projections Tab** - TCO calculator with timeline visualization

## How to Capture

1. Start the dashboard: `python src/dashboard.py`
2. Navigate to http://localhost:8050
3. Take screenshots of each tab
4. Save as PNG files named:
   - `overview.png`
   - `recommendations.png`
   - `pricing-models.png`
   - `instance-finder.png`
   - `projections.png`

Screenshots will be added to this directory and referenced in the README.
